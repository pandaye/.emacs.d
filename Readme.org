#+STARTUP: showall

* Pandaye 的 .emacs.d

个人 Emacs 配置，偏 TUI 使用，重点是模态编辑、Org 写作、阅读翻译和轻量开发。

** 安装

插件通过 =package.el= 和 =use-package= 自动安装，ELPA 源使用清华镜像。首次启动会刷新 archive 并安装缺失插件。

#+begin_src sh
git clone <repo> ~/.emacs.d
emacs
#+end_src

本地私有配置放在 =local-vars.local.el= ，例如订阅源、API key 和个人目录。

** 配置风格

- 模态编辑以 =meow= 为核心，配合自定义 modeline 展示状态；常用窗口、文件、项目操作集中在 =C-c= 前缀下。
- 补全与导航使用 =vertico= 、 =consult= 、 =orderless= 、 =projectile= 、 =dirvish= 和 =rg= 。
- 编程主力是 =lsp-bridge= ，进入编程模式后延迟加载；Common Lisp 单独使用 =SLIME= + =Corfu= 。
- Org 侧重写作和知识库： =org-roam= 、 =org-roam-ui= 、 =org-super-agenda= 、日记、GTD 和静态博客发布。
- 中文输入使用 =rimel= / Librime，仓库内维护 =rime/= 配置，并和 =meow= insert 状态联动。
- 阅读流使用 =elfeed= 、 =gt= 、 =sdcv= ；查词会记录单词和上下文句子。

** 配置结构

=init.el= 是唯一入口，按顺序做三件事：初始化包管理和 =use-package= 、加载 =custom-file= 、登记 =lisp/core= 、 =lisp/modules= 、 =lisp/features= 三个层目录并按固定顺序加载模块。模块清单和顺序直接写在入口里，启动行为一眼可读。自有代码按生命周期分为三层：

- =lisp/core/= ：启动默认值、本地私有值和全局键位。
- =lisp/modules/= ：按领域管理第三方包、hook、advice 和 mode 局部键位。
- =lisp/features/= ：可独立加载和测试的领域命令，不安装或配置第三方包。

配置模块使用 =init-*= 命名，例如 =init-reader= 和 =init-development= ；功能库使用领域名，例如 =translate= 和 =tmux-manager= 。依赖方向固定为：

#+begin_example
init.el -> core / modules -> features -> Emacs 内置库
#+end_example

全局键位集中在 =core/init-keybindings.el= ，各 mode 的局部键位留在所属模块。顶层固定加载现有全部模块，不提供 profile 或模块开关。

配置层自有符号使用 =pandaye/<domain>-*= 命名；独立功能库的符号以前缀化的库名命名，例如 =translate-*= 和 =org-ssh-*= 。迁移前已公开使用的符号保留兼容 alias，但新代码只引用规范名称。

运行 =make test= 会加载完整配置并执行行为契约、架构约束和功能 ERT；运行 =make compile= 会递归字节编译 =lisp/= 下的全部自有 Elisp，产物写入临时目录。

** 显示环境

同一份配置同时适配终端和图形界面，按帧类型分流：

- =modules/init-tui.el= ：终端专属——display-table 的截断/续行字形、OSC 52 剪贴板、OSC 12 光标颜色、关闭自动字符组合和 CJK 宽字符推断。
- =modules/init-gui.el= ：图形专属——默认字体与字号、CJK 和 emoji 字体、关闭原生对话框、像素滚动。字体可用 =pandaye/gui-font-family= 、 =pandaye/gui-font-height= 、 =pandaye/gui-cjk-font-family= 、 =pandaye/gui-emoji-font-family= 调整。

两者都在加载时判断一次，并对之后出现的帧挂 =after-make-frame-functions= ，所以 =emacs --daemon= 加 =emacsclient= （ =-c= 或 =-nw= ）也能拿到对应那套配置。光标颜色提示（meow 状态、输入法是否激活）在两种环境下都生效：终端发 OSC 12，图形界面写帧的 =cursor-color= 。

** 外部依赖

- =python3= ：阅读翻译会用 PySBD 做句子切分；首次启动会按 =requirements-translate.txt= 后台准备虚拟环境。
- =sdcv= ：本地 StarDict 查词，词典目录默认是 =~/.stardict/dic= 。
- Librime：供 =rimel= 输入法使用。
- =git= 、 =rg= ：项目管理和全文搜索依赖。
- 各语言的 LSP server 需按语言自行安装； =lsp-bridge= 本体会由配置自动拉取。

可选依赖：Common Lisp 使用 =ros run= 启动 =SLIME= ，没有 Lisp 开发需求可以不装。
