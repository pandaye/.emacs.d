# Changelog

All notable changes to org-opencode will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2025-XX-XX

### Added

- Org-mode frontend for the opencode AI coding agent
- Streaming AI response rendering (src-block and entry layouts)
- Tool call visualization with collapsible Org drawers
- Session management (create, fork, browse, history, adopt)
- SSE event streaming with automatic reconnect
- File change detection with auto-revert and diff viewer
- Tool approval UI for dangerous operations
- Model and agent selection
- Incremental delta rendering for streaming responses
- Todo/progress tracking from agent work
- Header-line status indicator
